Entity-Relationship (ER) Diagram

Visual representation of entities, attributes, primary keys, foreign keys and cardinalities

7 Entities 3NF Normalized

Organizer

1:N with Event
  • Organizer_ID PK
  • Name
  • Email (UNIQUE)
  • Phone

Category

1:N with Event
  • Category_ID PK
  • Category_Name (UNIQUE)
  • Description

Venue

1:N with Event
  • Venue_ID PK
  • Venue_Name
  • Location
  • Capacity (CHECK >0)

Event (Core Entity)

Holds Foreign Keys
  • Event_ID PK
  • Event_Name
  • Date
  • Time
  • Organizer_ID FK → Organizer
  • Venue_ID FK → Venue
  • Category_ID FK → Category
  • 1:N with Registration

Participant

1:N with Reg
  • Participant_ID PK
  • Name
  • Email (UNIQUE)
  • Phone

Registration

1:1 with Payment
  • Registration_ID PK
  • Participant_ID FK → Participant
  • Event_ID FK → Event
  • Registration_Date
  • Status

Payment

1:1 Dependent
  • Payment_ID PK
  • Registration_ID FK (UNIQUE 1:1)
  • Amount (>= 0)
  • Payment_Date
  • Payment_Status

Relational Integrity Rules:

🔗 Organizer (1) ——< (N) Event
🔗 Category (1) ——< (N) Event
🔗 Venue (1) ——< (N) Event
🔗 Event (1) ——< (N) Registration
🔗 Participant (1) ——< (N) Registration
🔗 Registration (1) ——— (1) Payment [UNIQUE FK]
